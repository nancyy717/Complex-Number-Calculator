# Complex Number Calculator

## Project Overview
A beginner-friendly C++ project that performs addition and subtraction of complex numbers using operator overloading.

## Objectives
- Store real and imaginary parts using a Complex class.
- Add two complex numbers using the overloaded + operator.
- Subtract two complex numbers using the overloaded - operator.
- Display complex numbers using the overloaded << operator.

## OOPS Concepts Used
- Classes and Objects
- Constructors
- Encapsulation
- Operator Overloading

## Requirements
- A C++ compiler such as Clang or GCC
- Visual Studio Code (optional)

## How to Compile and Run on macOS
```bash
clang++ main.cpp -o calculator
./calculator
```
